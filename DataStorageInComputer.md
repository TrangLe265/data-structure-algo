# How data is stored in computer

## Computer Memory
- *§§RAM*: Random Access Memory you loose the memory when you turn off the computer 
    - RAM has addresses, each shelf has 8 bit  or 1 byte
    - when the CPU need to access RAM, a memory controller helps CPU find it
    the Memory Controller need to know which shelf to look for the data
    the closer the data that are stored on shelves, the faster it is for the CPU to retrieve the info
    - it has fast access
    - CPU store the most recent data from RAM in a part called **cache**
- *Storage*: persistent data (permanent)
